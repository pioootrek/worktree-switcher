# Visual reference workspace

Before changing examples, read [README.md](README.md) and the linked owner
decision. The original approved PNG remains the visual authority; working
tokens and specimens are explicitly proposed interpretations.

Keep this directory independent of app routes, imports, build inputs and package
contents. Preserve direct local-file opening: use local assets and classic
scripts, without runtime APIs, network dependencies or a server requirement.

Add experiments only with actual content and their review status. Preserve the
approved reference and record owner acceptance before promoting an experiment.

For changes, check local links, JavaScript syntax and `git diff --check`.
Verify affected interactions, keyboard access and narrow layouts in a browser
when available; report unavailable browser verification honestly. Follow the
repository backlog guide when updating the linked decision record.
